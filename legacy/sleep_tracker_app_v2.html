Google Sheets Sync

Tự động đẩy dữ liệu lên file Excel của bạn

Cách lấy Link (URL):

  1. Mở Google Sheets tạo 1 file mới tên "Sleep Tracker".
  2. Vào Tiện ích mở rộng > Apps Script.
  3. Dán đoạn Code Google Script (được cung cấp riêng) vào.
  4. Bấm Triển khai (Deploy) > Tùy chọn triển khai mới.
  5. Chọn loại: Ứng dụng web. Quyền truy cập: Bất kỳ ai.
  6. Copy URL được tạo ra và dán vào ô bên trên.
